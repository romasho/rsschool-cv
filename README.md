# Raman Shalamitski — CV

Responsive CV based on the supplied Figma design, with light and dark themes.

GitHub Pages URL: https://romasho.github.io/rsschool-cv/

## Development

Open `index.html` in a browser or serve this directory with a static HTTP server.
No build step or dependencies are required.

## Validation

- W3C Nu HTML Checker: no errors or warnings (2026-09-12).
- Light and dark themes; the selected theme persists across reloads.
- Responsive layout checked at 320 px and desktop width.

## Submission

Publish the files on the `gh-pages` branch, verify the GitHub Pages URL, and
submit it through https://app.rs.school/course/student/cross-check-submit.
Local validation does not confirm deployment or RS App submission.

Task: https://github.com/rolling-scopes-school/qualifying-stage/blob/main/tasks/cv/README.md
